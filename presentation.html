Core Engine • Layer 1

Semantic Matching & Vector Optimization

Transformer embeddings with unit-length dot product acceleration

Transformer Embeddings (all-MiniLM-L6-v2): Encodes skills and project narratives into dense 384-dimensional conceptual vectors.
Unit L2 Normalization (||v|| = 1.0): Pre-scaling vectors simplifies standard Cosine Similarity directly to a blazing-fast dot product: np.dot(vec_a, vec_b).
Scientific 3-Tier Thresholds:
• ≥ 0.75 (Strong Match): Full credit (1.0) • Automatic approval
• 0.55 to 0.74 (Uncertain Match): Partial credit (0.5) • Flags recruiter for human-in-the-loop review
• < 0.55 (Missing): Zero credit (0.0)
Project Relevance Engine: Computes semantic alignment between student project portfolios and the target job domain.
In-Memory Caching Eliminates Redundant Neural Encodings Slide 4 / 8
Core Engine • Layer 2

Supervised Interview Readiness Classifier

Replacing arbitrary cutoffs with multivariate machine learning

The 5 Extracted Features (X)

  1. Required Skill Coverage: Mandatory skills match (0.0–1.0)
  2. Preferred Skill Coverage: Secondary skills match (0.0–1.0)
  3. Experience Ratio: Student / Job min experience
  4. Project Relevance: Semantic similarity score
  5. Coursework Overlap: Academic subject alignment

Dual-Model Benchmark

Logistic Regression (Primary): Highly interpretable, provides explicit linear coefficients (wi) and calibrated Sigmoid probabilities.
Random Forest (Benchmark): 50 decision trees capturing non-linear conditional interactions (e.g., exceptional project compensating experience).
